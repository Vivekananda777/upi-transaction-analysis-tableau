# UPI Transaction Analysis using Tableau

## Project Overview

This project analyzes 20,000 UPI transaction records using Tableau
to understand transaction patterns across cities, age groups,
payment methods, merchants, devices, banks, currencies and payment modes.

## Objectives

- Analyze transaction amount by city
- Segment transactions by customer age groups
- Compare payment methods across merchants
- Analyze transaction success and failure
- Identify geographic transaction patterns
- Build an interactive fintech analytics dashboard

## Dataset

- 20,000 transaction records
- 20 attributes
- Customer information
- Payment information
- Merchant information
- Bank information
- Geographic information

## Tools

- Tableau
- Microsoft Excel
- Data Visualization
- Calculated Fields
- Interactive Filters

## Key Tableau Features

- Calculated Age Groups
- Map Visualization
- Bar Charts
- Interactive Filters
- Dashboard Actions
- Aggregated Measures

## Key Insights

- Mumbai recorded the highest transaction amount at approximately
  5.05M.
- Customers in Age Group 3 represented 60% of transactions.
- Transaction amounts were relatively evenly distributed across
  Phone Number, QR Code and UPI ID payment methods.
- The overall transaction success rate was 80%.
- Transaction values were relatively evenly distributed across
  Bangalore, Delhi, Hyderabad and Mumbai.
